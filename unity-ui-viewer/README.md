# HaiTac — Unity Offline UI Viewer

**Status:** metadata-driven interactive Unity prototype. This is NOT the original game client, recovered Unity source, an official game, or a functional multiplayer server.

## Requirements

- Unity Hub with **Unity 2022.3.21f1** (or compatible 2022.3 LTS).
- Windows 10/11 and Unity Editor installed.
- Python 3, only needed if regenerating data from existing CSV reports.
- No login, external server, APK decompiler or XAPK download required to view the metadata demo.

## Start on Windows

1. Clone https://github.com/thanhtran2005isme-art/HaiTacDaiChien (the viewer does not require a Git LFS pull).
2. Unity Hub → Add project → select the folder **HaiTacDaiChien/unity-ui-viewer**.
3. Wait for the Unity package imports and compile.
4. Check that **Assets/StreamingAssets/ui-scenes.json** exists. It is generated by the lightweight GitHub workflow. If missing, run in CMD or PowerShell from repository root:

```powershell
py tools/build_unity_viewer_data.py --repo-root .
```

5. Unity menu → **Tools → HaiTac Offline UI Viewer → Create or Open Demo Scene**.
6. Press **Play**. Pick a scene in the left sidebar, use **Left/Right** arrow keys to switch, and click any colored region to inspect its underlying Unity metadata.

## Offline features

- Five scene candidates for four screenshots: ship upgrade, hero detail, island map A/B, and home/crew.
- Draws approximate UI boxes from RectTransform anchors, pivots, size, position and parent IDs.
- Shows candidate Sprite names, Spine component class names, Button/Text presence, inactive state, and missing Image references.
- Interactive inspector and scene navigation with clickable regions. Does not call GOSU or any server.
- **Demo: nâng cấp tàu +1** is clearly mock progress held only in memory. It is **not** original gameplay or economy logic.

Color legend: green = linked Sprite candidate; amber = Image without static Sprite; blue = Button; purple = text or Spine placeholder.

## Accuracy and rights

The 1600×900 projection is **hypothetical**. Original runtime CanvasScaler values were not recovered. Rotations, scale, Canvas masks, runtime LayoutGroup, nine-sliced Sprite art, animation skins and full behavior are not reconstructed. This project intentionally ships **no commercial artwork, avatars, audio, extracted Unity binaries, game screenshots, decompiled game code, or server credentials**. A shut-down game's intellectual property does not automatically enter the public domain.

## Data sources

The generator **tools/build_unity_viewer_data.py** reads already committed reports under reports/xapk:

- ui-screenshot-reference-previews.csv (reference scene roots)
- ui-hierarchy.csv, ui-components.csv, resolved-ui-components.csv
- scene-image-texture-links.csv
- scene-unresolved-images.csv
- scene-spine-components.csv

It writes **Assets/StreamingAssets/ui-scenes.json**, a compact dataset of names, object IDs, coordinates and reference markers only. The separate lightweight CI job regenerates this file without downloading the ~371 MB XAPK.

## Tests

GitHub Actions runs Python unit tests and validates that all five scene roots, transform IDs and parent links resolve. It does **not** compile or execute the Unity Editor here. You must confirm Unity Console has no errors and test Play Mode on your Windows Unity installation before treating the prototype as runtime-ready.
