3. Cấu trúc toàn bộ Source Code Backend C# cho Unity Game lớn
Mình đề xuất sử dụng ASP.NET Core 10 + Modular Monolith + Vertical Slice + Clean Architecture principles.
Kiến trúc này phù hợp cho Backend game multiplayer quy mô lớn, có Gateway, hệ thống tài khoản, nhân vật, trang bị, vật phẩm, kinh tế, matchmaking và giao tiếp với Dedicated Game Server.

Những module phù hợp cho game online có tài khoản, nhân vật, vật phẩm và tiến trình. Module tùy chọn chỉ triển khai khi thiết kế game thực sự cần.

Ở cấu trúc này, mỗi module ban đầu có một .csproj để tránh tạo hàng chục project nhỏ khi chưa cần. Các folder Domain, Features, Infrastructure vẫn là các ranh giới logic, được kiểm soát qua architecture tests.
Nếu đội ngũ rất lớn, có thể tách từng module thành các assembly Domain, Application, Infrastructure để thực thi quy tắc phụ thuộc ở mức compiler.
3.6. Luồng phụ thuộc giữa các project
Game.Api / Game.Worker

Modules
Domain · Features · Infrastructure

SharedKernel / Contracts / Abstractions

Gateway đứng trước API và không phụ thuộc trực tiếp vào các module nghiệp vụ. Domain không được phụ thuộc Infrastructure.
Các quy tắc cần áp dụng:
- Domain không tham chiếu EF Core, HTTP, Redis hoặc lớp truy cập database.
- Features điều phối use case, không viết trực tiếp logic truy cập dữ liệu vào endpoint.
- Infrastructure triển khai các interface do lõi nghiệp vụ cần.
- Các module không truy cập trực tiếp repository hoặc bảng riêng của module khác; ưu tiên contract và application service.
- Giao dịch mua vật phẩm, tiêu tiền, nhận thưởng phải có kiểm soát đồng thời, transaction và idempotency.
- Không tạo GenericRepository, BaseService, Manager khổng lồ cho toàn hệ thống.
3.7. Game Server nằm ở đâu?
Game Server xử lý real-time nên tách riêng khỏi Backend Web API:
GameProject/
├── client/
│   └── UnityGame/
│
├── backend/
│   └── src/
│       ├── Hosts/

│   ├── README.md
│   ├── ServerConfig/
│   └── BuildScripts/
│
└── shared/
    └── ProtocolSchemas/


Với Unity Dedicated Server, mã gameplay có thể được chia sẻ từ chính Unity project, sau đó build thành executable headless cho máy chủ. Không cần tạo một bộ combat C# thứ hai trong ASP.NET Core. Unity hỗ trợ Dedicated Server build và điều kiện biên dịch UNITY_SERVER.
